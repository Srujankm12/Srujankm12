## What I work on

- **AI agents and developer tools**: desktop apps that run coding agents, LLM gateways with usage-based credits, model evaluation and routing
- **SaaS platforms**: multi-tenant backends, billing and subscriptions, admin dashboards, CRMs and internal tools
- **Backend systems**: Go and Node.js services, job queues, real-time APIs, data migration between cloud providers
- **Desktop and mobile**: cross-platform desktop apps with Tauri and Rust, mobile apps with React Native and Flutter
- **Automation**: LLM chatbots, WhatsApp business automation, AI workflows
- **Shipping**: CI/CD, code signing and Apple notarization, auto-updates, deployment and monitoring
